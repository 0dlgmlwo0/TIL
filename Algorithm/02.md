
# 데이터의 표현 정리 (2주차)

---

## ✅ 정보와 데이터의 차이
- **정보(Information)** : 사람이 이해할 수 있도록 의미 있게 정리된 자료
- **데이터(Data)** : 컴퓨터가 처리할 수 있도록 0과 1로 변환된 형태

---

## ✅ 컴퓨터는 왜 0과 1만 쓸까?
- 컴퓨터 기억장치는 전기 신호(ON/OFF)로 동작
- 그래서 **2진수**만 사용

---

## ✅ 데이터 단위
| 단위   | 설명                |
|--------|---------------------|
| 1 bit  | 0 또는 1             |
| 1 byte | 8 bit               |
| 1 KB   | 1,024 byte          |
| 1 MB   | 1,024 KB            |
| 1 GB   | 1,024 MB            |
| 1 TB   | 1,024 GB            |

---

## ✅ 문자 인코딩
- **ASCII 코드** : 영어 기반, 7비트 (예: A = 65)
- **Unicode** : 전 세계 언어 지원, UTF-8 방식

---

## ✅ 자료형 (Data Type)
| 자료형     | 예시         | 설명      |
|------------|--------------|-----------|
| int        | 1, -5        | 정수형     |
| float      | 3.14, -0.1   | 실수형     |
| char / str | 'A', "Hi"    | 문자/문자열 |
| bool       | True, False  | 참/거짓    |

---

## ✅ 자료구조의 시작
- 여러 데이터를 효율적으로 관리하기 위해 **자료구조** 사용
- ex) 배열, 리스트 등

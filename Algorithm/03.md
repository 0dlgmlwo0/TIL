
# 기본 자료구조 정리 (3주차 1강)

---

## ✅ 자료구조 분류
| 구분          | 설명             | 예시              |
|---------------|------------------|-------------------|
| 선형 구조     | 순서대로 저장    | 배열, 연결 리스트, 스택, 큐 |
| 비선형 구조   | 순서 없음        | 트리, 그래프      |

---

## ✅ 배열 (Array)
- 연속된 공간에 데이터를 순서대로 저장
- 인덱스로 빠르게 접근 (O(1))
- 크기 고정, 삽입/삭제 비효율적

---

## ✅ 연결 리스트 (Linked List)
- 노드(데이터 + 포인터)로 구성
- 크기 제한 없음, 삽입/삭제 용이
- 접근은 느림 (O(n))

### 🔹 연결 리스트 구조 예시
```
[월 | ➔ ] ➔ [화 | ➔ ] ➔ [수 | ➔ ] ➔ [목 | ➔ ] ➔ [금 | null]
```

### 🔹 중간 삽입 예시 ('수'와 '목' 사이에 '토' 삽입)
```
[수 | ➔ ] ➔ [토 | ➔ ] ➔ [목 | ➔ ]
```

## ✅ 배열 vs 연결 리스트 비교
| 구분        | 배열         | 연결 리스트   |
|-------------|--------------|---------------|
| 메모리      | 연속 공간    | 포인터 연결   |
| 크기        | 고정         | 가변          |
| 접근 속도   | 빠름 (O(1))  | 느림 (O(n))   |
| 삽입/삭제   | 비효율적     | 효율적        |


# 자료구조와 알고리즘 정리 (1주차 + 알고리즘 1강)

---

## 📘 1주차: 자료구조와 알고리즘 기초

### ✅ 자료구조란?
- 데이터를 효율적으로 저장하고 관리하는 방법
- 삽입, 삭제, 수정, 검색을 효율적으로 수행
- 메모리 절약 + 속도 향상

### ✅ 알고리즘이란?
- 문제를 해결하기 위한 단계적 절차
- 입력 → 처리 → 출력
- 요건: 입력, 출력, 정확성, 유한성, 수행 가능성

### ✅ 자료구조와 알고리즘의 관계
- 자료구조: 데이터를 **어디에** 정리할지
- 알고리즘: 데이터를 **어떻게** 처리할지

---

## 📘 알고리즘 1강 1차시: 알고리즘 개요와 사례

### ✅ 탐색 알고리즘
- **순차탐색**: 앞에서부터 하나씩 찾기 (O(n))
- **이진탐색**: 정렬된 데이터에서 반씩 나눠서 찾기 (O(log n))

### ✅ 그리디 알고리즘 (Greedy)
- 매 순간 최선의 선택을 하는 방식
- 예시: 거스름돈 최소 동전 개수

### ✅ 한붓그리기 (Eulerian Path)
- 모든 선분을 한 번씩만 지나가는 경로
- 조건: 홀수 차수 정점이 0개 or 2개

### ✅ 가짜 동전 찾기 (Divide & Conquer)
- 동전 더미를 반씩 나눠서 가짜 동전 찾기
- 시간복잡도: log₂(n)

---

## 📘 알고리즘 1강 2차시: 알고리즘 표현 & 시간복잡도

### ✅ 알고리즘 표현 방법
1. 자연어
2. 의사코드 (Pseudo Code)
3. 순서도 (Flow Chart)

### ✅ 시간복잡도 (Time Complexity)
- 입력 크기에 따른 연산 횟수
- 효율적인 알고리즘 설계의 핵심 지표

### ✅ 점근적 표기법
- **O(Big-Oh)** : 최악의 경우
- **Ω(Big-Omega)** : 최선의 경우
- **Θ(Theta)** : 평균적인 경우

### ✅ 자주 사용하는 Big-O
| 표기      | 설명        | 예시        |
|-----------|-------------|-------------|
| O(1)      | 상수 시간   | 즉시 반환   |
| O(log n)  | 로그 시간   | 이진탐색    |
| O(n)      | 선형 시간   | 순차탐색    |
| O(n log n)| 로그선형    | 효율적 정렬 |
| O(n²)     | 제곱 시간   | 버블정렬    |
| O(2ⁿ)     | 지수 시간   | 완전탐색    |

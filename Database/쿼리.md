
# 병원 검색 쿼리 가이드

병원 데이터를 정규화한 후, 다양한 검색 조건에 따라 병원을 조회할 수 있습니다. 아래는 가능한 검색 유형과 그에 대응하는 SQL 쿼리 예시입니다.

---

## 1. 단일 진료과목 검색

**예시:** 내과 있는 병원

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name = '내과';
```

---

## 2. 다중 진료과목 모두 포함 검색

**예시:** 내과와 정형외과 모두 있는 병원

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name IN ('내과', '정형외과')
GROUP BY m.hospital_code
HAVING COUNT(DISTINCT s.subject_name) = 2;
```

---

## 3. 다중 진료과목 중 하나 이상 포함

**예시:** 피부과 또는 산부인과 병원

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name IN ('피부과', '산부인과')
GROUP BY m.hospital_code;
```

---

## 4. 진료과목 + 지역 검색

**예시:** 분당구 내과 병원

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name = '내과'
  AND m.district_name = '분당구';
```

---

## 5. 야간 응급 진료 가능 병원

**예시:** 야간 응급 가능한 정형외과 병원

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '정형외과'
  AND d.night_emergency_available = 'Y';
```

---

## 6. 평일 진료시간 조건 포함

**예시:** 18시 이후까지 진료하는 내과 병원

```sql
SELECT m.*, d.weekday_reception
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '내과'
  AND d.weekday_reception LIKE '%18시%';
```

---

## 7. 주차 가능 병원

**예시:** 주차 가능한 소아청소년과 병원

```sql
SELECT m.*, d.parking_capacity
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '소아청소년과'
  AND d.parking_capacity > 0;
```

---

## 8. 홈페이지 있는 병원

**예시:** 이비인후과 병원 중 홈페이지 있는 곳

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name = '이비인후과'
  AND m.hospital_homepage IS NOT NULL
  AND m.hospital_homepage != '';
```

---

## 9. 모든 조건 복합 검색

**예시:** 성남시 분당구 내과 병원 중 야간 응급 가능하고 주차 가능한 곳

```sql
SELECT m.*
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '내과'
  AND m.district_name = '분당구'
  AND d.night_emergency_available = 'Y'
  AND d.parking_capacity > 0;
```

---

## 10. 진료과목별 병원 수 통계

```sql
SELECT subject_name, COUNT(*) AS hospital_count
FROM hospital_medical_subject
GROUP BY subject_name
ORDER BY hospital_count DESC;
```

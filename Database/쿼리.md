
# 병원 검색 쿼리 가이드 (명시적 컬럼명 버전)

---

## 1. 단일 진료과목 검색

**예시:** 내과 있는 병원

```sql
SELECT m.hospital_code,
       m.hospital_name,
       m.province_name,
       m.district_name,
       m.hospital_address,
       m.hospital_tel,
       m.hospital_homepage,
       m.doctor_num,
       m.coordinate_x,
       m.coordinate_y
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name = '내과';
```

---

## 2. 다중 진료과목 모두 포함 검색

**예시:** 내과와 정형외과 모두 있는 병원

```sql
SELECT m.hospital_code,
       m.hospital_name,
       m.province_name,
       m.district_name,
       m.hospital_address,
       m.hospital_tel,
       m.hospital_homepage,
       m.doctor_num,
       m.coordinate_x,
       m.coordinate_y
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE s.subject_name IN ('내과', '정형외과')
GROUP BY m.hospital_code
HAVING COUNT(DISTINCT s.subject_name) = 2;
```

## 3. 다중 진료과목 중 하나 이상 포함

**예시:** 피부과 또는 산부인과 병원

## 4. 진료과목 + 지역 검색

**예시:** 분당구 내과 병원

```sql

       m.district_name,
```

## 5. 야간 응급 진료 가능 병원

```sql
SELECT m.hospital_code,
       m.hospital_name,
       m.province_name,
       m.district_name,
       m.hospital_address,
       m.hospital_tel,
       m.hospital_homepage,
       m.doctor_num,
       m.coordinate_x,
       m.coordinate_y
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '정형외과'
  AND d.night_emergency_available = 'Y';
```

## 9. 복합 조건 검색

```sql
SELECT m.hospital_code,
       m.hospital_name,
       m.province_name,
       m.district_name,
       m.hospital_address,
       m.hospital_tel,
       m.hospital_homepage,
       m.doctor_num,
       m.coordinate_x,
       m.coordinate_y, d.weekday_reception, d.parking_capacity
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
JOIN hospital_detail d ON m.hospital_code = d.hospital_code
WHERE s.subject_name = '내과'
  AND m.district_name = '분당구'
  AND d.parking_capacity > 0
  AND d.night_emergency_available = 'Y'
  AND d.weekday_reception LIKE '%18시%';
```

## 10. 진료과목별 병원 수 통계

```sql
SELECT subject_name, COUNT(*) AS hospital_count
FROM hospital_medical_subject
GROUP BY subject_name
ORDER BY hospital_count DESC;
```


```sql
SELECT m.hospital_name, s.subject_name
FROM hospital_main m
JOIN hospital_medical_subject s ON m.hospital_code = s.hospital_code
WHERE m.hospital_name LIKE '%김이비인후과%';
```

## ✅ 설명

- `hospital_main` 테이블에서 병원 이름을 기준으로 검색합니다.
- `hospital_medical_subject`와 병원 코드를 기준으로 JOIN하여 진료과목 정보를 가져옵니다.
- `LIKE '%김이비인후과%'`는 병원 이름에 '김이비인후과'가 포함된 병원을 찾습니다.

## ✅ 변형 예시

### 병원이름 정확히 일치하는 경우
```sql
WHERE m.hospital_name = '김이비인후과의원'
```

### 여러 병원을 동시에 조회하는 경우
```sql
WHERE m.hospital_name IN ('김이비인후과의원', '한빛의원')
```

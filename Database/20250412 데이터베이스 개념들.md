# 오늘 학습한 데이터베이스 개념들

## 1. 외래키 (Foreign Key)
- **외래키**는 한 테이블의 필드가 다른 테이블의 **기본키**(Primary Key) 또는 고유 키를 참조하는 관계를 설정할 때 사용됩니다.
- 외래키는 데이터를 유기적으로 연결하여 데이터의 무결성을 보장합니다.
- 예를 들어, `hospital_detail` 테이블의 `hospital_code`는 `hospital_main` 테이블의 `hospital_code`를 참조하여 두 테이블을 연결합니다.

## 2. 기본키 (Primary Key)
- **기본키**는 각 레코드를 고유하게 식별할 수 있는 하나 이상의 컬럼입니다.
- 기본키는 중복을 허용하지 않으며 `NULL` 값도 허용하지 않습니다.
- `hospital_code`는 병원 데이터에서 병원을 고유하게 식별하는 기본키로 사용할 수 있습니다.

## 3. 관계형 데이터베이스에서 테이블 간 관계
- 관계형 데이터베이스에서는 여러 테이블을 **외래키**를 통해 연결합니다.
- 예를 들어, `hospital_main` 테이블의 `hospital_code`를 `hospital_detail` 테이블의 `hospital_code`로 연결하여 병원에 대한 상세 정보를 제공할 수 있습니다.
- **1:N 관계**: 한 병원이 여러 개의 상세 정보나 교통편 정보를 가질 수 있으므로, 병원 정보를 기준으로 다른 테이블을 참조할 수 있습니다.

## 4. `JOIN` 쿼리
- `JOIN`은 여러 테이블을 결합하여 하나의 결과를 생성하는 SQL 명령어입니다.
- 예를 들어, 병원 이름을 기준으로 다른 테이블의 정보를 결합하여 원하는 병원의 모든 정보를 출력할 수 있습니다.

# 감성 다이어리 앱 기능 정리

## 📅 달력 및 일기 작성 기능
앱의 메인 화면은 `TableCalendar` 패키지를 활용하여 달력 형태로 구성하였습니다.  
사용자가 특정 날짜를 선택하면 `onDaySelected` 콜백을 통해 해당 날짜가 저장되고,  
`Navigator.push`를 사용해 일기 작성 화면으로 자연스럽게 전환됩니다.  
이를 통해 날짜별로 개별 일기를 작성하고 관리할 수 있도록 설계하였습니다.

## 📝 일기 저장 기능
작성된 일기는 앱을 종료하거나 재실행해도 유지되도록 `SharedPreferences`를 이용하여 로컬에 저장됩니다.  
이 방식은 간단한 텍스트 기반 데이터의 저장 및 불러오기에 적합하며,  
사용자가 이전에 작성한 내용을 그대로 확인하고 수정할 수 있도록 도와줍니다.

## 🖼️ 사진 첨부 및 저장 기능
사진 첨부 기능은 `image_picker` 패키지를 통해 구현하였고,  
사용자가 선택한 사진은 `path_provider`를 이용해 앱 내부 저장소에 복사 및 저장됩니다.  
이 구조는 Firebase 등 외부 클라우드 연동 없이도 안정적인 로컬 이미지 저장 및 불러오기를 가능하게 하며,  
사용자의 프라이버시를 고려한 설계입니다.

## 🎵 음악 재생 기능
일기와 함께 감성적인 분위기를 더하기 위해 `audioplayers` 패키지를 사용하여  
배경 음악 재생 기능을 추가했습니다.  
앱에 포함된 mp3 파일을 `assets` 폴더에서 불러와 재생하며,  
`ReleaseMode.loop` 옵션을 통해 반복 재생이 가능하게 구성했습니다.  
이를 통해 사용자에게 몰입감 있는 다이어리 경험을 제공합니다.

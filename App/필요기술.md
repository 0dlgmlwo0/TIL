# 📌 향후 기능 구현 계획 및 필요 기술 정리

## ✅ 앞으로 구현할 기능

| 기능 구분           | 세부 내용                                                       | 우선순위 |
|--------------------|----------------------------------------------------------------|----------|
| 📸 사진 첨부        | 사용자가 하루에 한 장 사진을 업로드할 수 있도록 함              | 높음     |
| 💾 로컬 저장 기능    | SharedPreferences 또는 Hive를 이용해 로컬에 일기/사진 저장        | 높음     |
| 📑 다이어리 상세 화면 | 날짜 클릭 시 상세 작성 화면으로 이동하여 일기, 사진, 음악 입력 가능 | 높음     |
| 🎵 음악 업로드       | mp3 파일을 선택하거나 앱 내 기본 음악을 고를 수 있도록 구현       | 중간     |
| ▶️ 음악 재생 기능    | 선택한 음악을 해당 날짜에 맞춰 스트리밍 또는 로컬에서 재생       | 중간     |
| 🎨 UI 개선 및 꾸미기 | 감성 UI를 위한 테마 적용, 카드 뷰 적용 등                     | 낮음     |
| ☁️ Firebase 연동     | Firestore/Storage/Auth를 활용한 클라우드 저장 및 로그인 기능     | 선택사항 |

---

## 🛠 필요한 기술 스택 및 패키지

| 기능                 | 사용 기술 / 패키지                                |
|----------------------|---------------------------------------------------|
| 사진 업로드           | `image_picker`, `permission_handler`             |
| 로컬 저장             | `shared_preferences`, `hive`, `path_provider`    |
| 상세 페이지 라우팅     | `Navigator`, `MaterialPageRoute`                 |
| 음악 업로드           | `file_picker`, `permission_handler`              |
| 음악 재생             | `audioplayers`, `just_audio`                     |
| UI 테마 및 커스터마이징 | `ThemeData`, `GoogleFonts`, `Custom Widgets`     |
| Firebase 연동         | `firebase_core`, `firebase_auth`, `cloud_firestore`, `firebase_storage` |

---

## ⏳ 예상 작업 순서

1. 📑 날짜 클릭 시 상세 입력 페이지 라우팅.
2. 📸 상세 입력 페이지에 사진 업로드 구현.
3. ✏️ 일기 텍스트 필드 구현 및 저장 처리.
4. 💾 로컬 저장 처리. (SharedPreferences 또는 Hive)
5. 🎵 음악 업로드 및 재생 기능 추가
6. 🎨 UI/UX 디자인 개선 (카드 스타일, 테마, 아이콘).
7. ☁️ Firebase 연동 (선택).

---

> ✨ 위 작업들은 우선 로컬 중심으로 진행 후, 시간 여유 시 Firebase 연동으로 확장 가능합니다.

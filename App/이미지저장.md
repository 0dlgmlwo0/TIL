
# 📦 Flutter 로컬 저장 방식 요약

Flutter 앱에서 데이터를 로컬에 저장하는 대표적인 방법 두 가지를 정리한 문서입니다.

---

## ✅ 1. `shared_preferences`

- **간단한 문자열, 숫자 저장에 적합**
- 앱 종료 후에도 유지됨
- **사용 예시 (일기 텍스트 등)**:

```dart
final prefs = await SharedPreferences.getInstance();
prefs.setString('2025-06-01', '오늘은 감성적인 하루였다.');
```

- 단점: 이미지 저장은 불가

---

## ✅ 2. `path_provider` + `dart:io`

- **텍스트 파일, 이미지 등 파일 단위 저장 가능**
- 앱의 내부 저장소에 직접 접근

**일기 텍스트 저장 예시:**

```dart
final directory = await getApplicationDocumentsDirectory();
final file = File('${directory.path}/diary_2025-06-01.txt');
await file.writeAsString('오늘은 감성적인 하루였다.');
```

**이미지 저장 예시:**

```dart
final img = File(pickedFile.path);
await img.copy('${directory.path}/img_2025-06-01.png');
```

---

## 📊 방식 비교

| 옵션 | 일기 텍스트 저장 | 이미지 저장 | 사용 난이도 | 추천 상황 |
|------|------------------|--------------|---------------|-------------|
| `shared_preferences` | ✅ | ❌ | 매우 쉬움 | 간단한 메모 |
| `path_provider` + `File` | ✅ | ✅ | 중간 | 일기 + 사진 저장 |

---

## 📌 추천

- 처음엔 `shared_preferences`로 간단한 저장 구현 후
- 향후 필요에 따라 `파일 저장 방식`으로 확장

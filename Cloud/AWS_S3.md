
# 📦 AWS S3 정리 (Simple Storage Service)

## 💡 S3란?
- AWS의 대표 **객체 스토리지 서비스**
- 무제한 확장 가능, 99.999999999% 내구성 제공
- 데이터 저장, 백업, 정적 웹 호스팅 등에 활용

---

## 📂 버킷(Bucket)과 객체(Object)
- **버킷**: 데이터를 담는 공간 (디렉토리 개념)
  - 전 세계 고유 이름 필요 (중복 불가)
- **객체**: 실제 저장 파일 (Owner, Key, Value, Metadata, Version ID)

---

## 🛡️ 내구성 & 가용성
- **내구성**: 데이터 손실 방지 (11 9's, 최소 3개 AZ 복제)
- **가용성**: 언제든 접근 가능 (SLA 99.9% 이상)

---

## 🗂️ S3 스토리지 클래스

| 클래스                | 내구성        | 가용성   | 특징                          |
|-----------------------|---------------|----------|-------------------------------|
| Standard              | 99.999999999% | 99.99%   | 자주 접근 데이터              |
| Intelligent-Tiering   | 99.999999999% | 99.99%   | 자동 비용 최적화              |
| Standard-IA           | 99.999999999% | 99.99%   | 가끔 접근, 저렴               |
| One Zone-IA           | 99.999999%   | 99.95%   | 단일 AZ, 중요도 낮은 데이터  |
| Glacier               | 99.999999999% | 복원 후  | 장기 보관, 느린 복원          |
| Glacier Deep Archive  | 99.999999999% | 복원 후  | 법적 보관용, 최대 12시간 복원 |
| S3 on Outposts        | -             | -        | 온프레미스 환경               |

---

## 🔒 S3 보안
- 기본 **비공개(Private)** 생성
- 퍼블릭 접근 시 **Bucket Policy** 또는 **IAM Policy** 필요
- 리소스 기반 정책 예시:

```json
{
  "Effect": "Allow",
  "Principal": "*",
  "Action": "s3:GetObject",
  "Resource": "arn:aws:s3:::my-bucket-name/*"
}
```

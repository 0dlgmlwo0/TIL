
# 🌐 AWS S3 정적 웹사이트 호스팅 실습 정리

## 💡 S3 정적 호스팅이란?
- S3 버킷을 이용해 **HTML 파일**을 웹사이트처럼 서비스
- 서버 없이 정적 페이지 제공 가능

---

## 🚀 실습 절차
1. **버킷 생성**
   - 퍼블릭 엑세스 허용
2. **파일 업로드**
   - `index.html`
   - `class/img/image.png`
3. **버킷 정책 설정**
   - 기본적으로 S3는 비공개
   - 퍼블릭 접근 허용을 위한 정책 추가

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicWebsiteAllow",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::sgu-202500-s3/*"
    }
  ]
}
```

---

## 🎯 추가 설정 예시
- **특정 폴더만 허용**
- **특정 IP만 접근 허용**
- **특정 폴더 다운로드 제한**

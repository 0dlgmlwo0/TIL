
# 🌐 AWS 클라우드 핵심 개념 & 아키텍처 정리

## 1️⃣ AWS 주요 서비스 개요
- **컴퓨팅**
  - **EC2**: 가상 서버 (온디맨드/스팟 인스턴스)
  - **Lambda**: 서버리스 컴퓨팅, 이벤트 기반 실행
- **스토리지**
  - **S3**: 객체 스토리지, 정적 웹 호스팅
  - **EBS**: 블록 스토리지 (EC2용)
- **네트워크**
  - **VPC**: 가상 네트워크 구성
  - **Route 53**: DNS 서비스
  - **CloudFront**: CDN 서비스
- **데이터베이스**
  - **RDS**: 관리형 관계형 DB (MySQL 등)
  - **DynamoDB**: NoSQL (키-값 저장소)
- **보안**
  - **IAM**: 사용자 및 권한 관리
  - **Security Group**: 트래픽 제어

---

## 2️⃣ AWS 인프라 구조
- **Region (리전)**: AWS 데이터센터의 물리적 위치 (예: 서울 `ap-northeast-2`)
  - 서비스 제공 지역, 법적 요구사항, 지연속도 고려
  - `us-east-1` : AWS 서비스가 최초로 출시되는 리전
- **Availability Zone (AZ, 가용영역)**: 리전 내 다수의 데이터센터
  - 재해 복구, 빠른 네트워크 연결
- **Edge Location (엣지 로케이션)**: 콘텐츠를 빠르게 전달하는 거점 (CloudFront 사용)
  - 예: 한국에서 넷플릭스 볼 때 속도 개선

---

## 3️⃣ 글로벌 서비스 vs 리전 서비스
- **글로벌 서비스**: 전 세계 공통 (예: IAM, Route53)
- **리전 서비스**: 특정 리전 기반 서비스 (대부분 AWS 서비스)

---

## 4️⃣ VPC (Virtual Private Cloud)
- **목적**: 외부와 격리된 가상 네트워크 구축
- **구성요소**
  - **Subnet**: VPC 내 네트워크 구역
  - **Route Table**: 트래픽 경로 지정
  - **Internet Gateway (IGW)**: 퍼블릭 인터넷 연결
  - **NAT Gateway**: 프라이빗 서브넷의 인터넷 접근
  - **VPC Endpoint**: AWS 서비스와 비공개 연결

---

## 5️⃣ IAM (Identity and Access Management)
- **역할**: AWS 리소스 접근 제어
- **구성**
  - **User**: 개별 사용자 계정
  - **Group**: 사용자 그룹
  - **Role**: 임시 권한 부여
  - **Policy**: JSON 형식 권한 규칙
  - **MFA**: 다중 인증
- **주의사항**
  - 루트 계정 최소 사용
  - 최소 권한 원칙 준수
  - 액세스 키 노출 금지 (GitHub 업로드 X)

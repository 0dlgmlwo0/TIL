
# 💻 AWS EC2 정리 (Elastic Compute Cloud)

## 1️⃣ EC2 기본 개념
- **EC2**: AWS에서 제공하는 가상 서버 서비스
- **인스턴스**: EC2로 생성한 개별 가상 서버
- 주요 작업:
  - 생성, 시작, 중지, 종료, 삭제
  - 인스턴스 타입 변경
  - 보안 설정 (Security Group)
  - 모니터링 설정

---

## 2️⃣ EC2 생성 과정
1. **AWS 콘솔 접속** → EC2 서비스 선택 (서울 리전)
2. 인스턴스 시작 → 이름 지정 (예: `sgu-202500-ec2test`)
3. OS 선택: **Amazon Linux 2**
4. 인스턴스 타입: **t3.nano**
5. **키페어 생성** (.pem 파일 다운로드 후 개인 메일로 보관)
6. 보안 그룹 설정 후 인스턴스 시작

---

## 3️⃣ 접속 방법
- **Linux/Mac**: `.pem` 파일로 SSH 접속
- **Windows**: `.pem` → `.ppk` 변환 (Putty 사용)
- Putty로 접속: IP 입력 → SSH 설정 → ppk 파일 적용 → 로그인: `ec2-user`

---

## 🔑 PEM vs PPK 설명

### ✅ PEM (.pem)
- **PEM (Privacy-Enhanced Mail)** 형식의 키 파일
- 주로 **Linux**나 **macOS**에서 사용
- SSH 접속 시 기본적으로 사용 가능
- 예시:  
  ```bash
  ssh -i "my-key.pem" ec2-user@<EC2-공인IP>
  ```

### ✅ PPK (.ppk)
- **PPK (PuTTY Private Key)** 형식의 키 파일
- **Windows** 환경에서 사용하는 SSH 클라이언트인 **PuTTY** 전용
- `.pem` 파일을 **Puttygen**으로 변환해서 사용

### 🔄 변환 방법
1. [Putty.org](https://www.putty.org) 에서 **Puttygen** 다운로드
2. `.pem` 파일을 불러오기 (Load)
3. **Save private key** 클릭 → `.ppk` 파일 생성
4. Putty 접속 시 해당 `.ppk` 파일 사용

## 4️⃣ 인스턴스 상태
| 상태           | 설명        |
|----------------|-------------|
| running        | 실행 중     |
| stopped        | 중지됨     |
| terminated     | 종료됨     |
| pending        | 대기 중     |
| stopping       | 중지 중     |
| rebooting      | 재부팅 중   |
| shutting-down  | 종료 중     |

---

## 5️⃣ 보안 그룹 (SG) 설정
- 인바운드 규칙 편집 → ICMP, HTTP 등 필요한 포트 추가
- 웹서버 구축 시 **HTTP(80번 포트)** 오픈 필수

---

## 6️⃣ 인스턴스 타입 변경 & 삭제
- 중지 후 인스턴스 타입 변경 (예: t3.nano → t3.micro)
- 필요시 인스턴스 삭제 후 재생성

---

## 7️⃣ EC2 웹서버 구축 실습
1. Putty 접속 후 `sudo su -` (슈퍼유저)
2. `yum install httpd -y` (Apache 설치)
3. `systemctl start httpd` (웹서버 실행)
4. `/var/www/html/` 경로에 `index.html` 생성
5. 브라우저에서 EC2 IP로 접속해 웹페이지 확인

---

## 8️⃣ 모니터링 & 자동화 (CloudWatch)
- **모니터링 설정**: 대시보드 추가
- **CPU 경고 설정**
  - 지표: CPUUtilization
  - 임계값: 30%
  - 알람 설정 → 이메일로 알림 받기
- **네트워크 경고 설정**
  - 지표: NetworkOut ≥ 20000
  - 알람 이름: `High_Network_Alarm`

---

## 9️⃣ 부하 테스트 실습
- **CPU 부하**: `stress-ng` 툴 사용
- **네트워크 부하**: `iperf3` 툴 사용
- 부하 발생 시 CloudWatch 알람 확인
